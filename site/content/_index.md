A reproducible NixOS configuration for laptops, managed as a Nix flake.
This site collects the guides, reference pages and decision records that explain how it works and why.

Start with the [overview](@/overview.md), or install a machine with the [installation guide](@/guides/install.md).
Browse the [decision records](@/decisions/_index.md) to see why the project made its main choices.
